# Product Manager Workbench Visual Profile

This profile applies only to the Product Manager Workbench project. Do not inherit these values in another project.

## Project Identity

- Product: local-first AI workbench for product managers
- Platform: desktop application
- Current frontend: AionUi with Electron and React
- Primary use: repeated, information-dense product work rather than marketing or entertainment

## Design Dials

- Variance: `4/10` — recognizable and intentional without experimental art direction
- Motion: `2/10` — restrained motion focused on state changes and feedback
- Density: `8/10` — information-dense productivity interface

When running a project-wide design-system search for this project, pass:

```text
--variance 4 --motion 2 --density 8
```

## Boundaries

- Prefer clarity, scanability, stable navigation, and efficient repeated actions.
- Avoid cinematic motion, marketing-page composition, ornamental dashboards, and novelty that competes with work.
- Preserve approved product requirements and existing AionUi behavior unless the user approves a change.
- Present visual directions for review before modifying production UI.
